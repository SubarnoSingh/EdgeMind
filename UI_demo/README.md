# EdgeMind UI Reference

These files are visual references for the EdgeMind Android UI redesign.

The reference images define the desired:
- visual language
- spacing
- typography hierarchy
- card style
- rounded components
- gradients
- navigation patterns
- Ask/Memory interaction
- bottom input interaction

IMPORTANT:
These are design references, not a literal UI to copy.

Adapt the visual language to EdgeMind's actual functionality:
- Ask
- Memory
- Local RAG
- Cloud escalation
- Cloud provenance
- Explicit Save to Memory
- Synchronization
- Settings

Do not introduce unrelated features from the reference designs.
Do not modify the existing backend, RAG, sync, Qdrant, or cloud architecture
for visual changes.
